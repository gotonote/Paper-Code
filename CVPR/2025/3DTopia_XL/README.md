# 3DTopia-XL - CVPR 2025

## 论文信息

- **标题**: 3DTopia-XL: High-Quality 3D PBR Asset Generation via Primitive Diffusion
- **作者**: 3DTopia
- **链接**: https://github.com/3DTopia/3DTopia-XL
- **会议**: CVPR 2025 Highlight

## 核心贡献总结

1. 提出首个基于Primitive Diffusion的3D资产生成方法
2. 支持PBR材质的高质量3D模型生成
3. 实现了从文本到3D的直接生成

## 方法概述

1. **Primitive表示**: 使用基础几何图元表示3D形状
2. **扩散模型**: 分步生成primitive属性
3. **PBR材质**: 预测物理渲染材质参数
